### ✨ Ce que vous pouvez faire

- 🇫🇷 **Parcourir** des catégories et sous-catégories traduites en français.
- 🎞️ **Explorer** les films, séries, animés, genres, acteurs, réalisateurs, décennies, plateformes, récompenses et autres sélections.
- 🎛️ **Personnaliser** les sources et l'ordre des rangées, avec un aperçu.
- 📦 **Exporter** une configuration JSON, même sans compte Nuvio.
- 📺 **Envoyer** une configuration vers Nuvio lorsque ses API et votre compte le permettent.

### 🚀 Démarrer

Ouvrez l'[interface web](https://anderson76389.github.io/Ma-Collection/), choisissez vos dossiers puis exportez votre configuration.

Pour tester localement (Git et Python nécessaires) :

```bash
git clone https://github.com/anderson76389/Ma-Collection.git
cd Ma-Collection
python -m http.server 8000
```

Accédez à **http://localhost:8000**.

### ℹ️ À savoir

**Ma-Collection organise des catalogues : ce n'est pas un service de streaming.** Les classements Top 10 provenant de listes TMDB/Trakt sont susceptibles de dépendre de leurs propriétaires ; leur mise à jour n'est pas garantie. Certaines images et intégrations utilisent encore des services externes. Une copie des médias ne remplace pas automatiquement les URL utilisées par les catalogues.
