    Exporter vers Kovelyx PC

    Cliquez sur Importer directement pour envoyer votre sélection à Kovelyx PC. Ouvrez d’abord Kovelyx PC. L’import se fait directement par la connexion locale, sans lien Windows kovelyx://, puis Kovelyx vous demande de confirmer le compte, le profil et le remplacement ou l’ajout.

    Protection des données : vous choisissez le profil cible et si vous voulez remplacer ou compléter les collections. Kovelyx demande une confirmation et sauvegarde les anciennes collections avant toute modification. La copie et le téléchargement JSON restent disponibles en secours.

    Les extensions utilisées par les catalogues doivent également être installées et configurées dans Kovelyx.

    Préparation de votre sélection initiale…

    Enregistrer votre configuration

    Utilisez le même e-mail et le même mot de passe sur Ma-Collection et dans Kovelyx PC. Il faut connecter les deux à un même serveur de comptes compatible Supabase. Le mode sans compte reste disponible.

    Serveur de comptes Kovelyx

    Renseignez le serveur et la clé publique configurés dans les paramètres serveur de Kovelyx. Si vous n'avez pas encore de serveur, l'inscription ne peut pas être activée sur un simple site GitHub Pages.

    Les identifiants ne sont jamais enregistrés dans les catalogues JSON. Pour sauvegarder des clés privées, utilisez séparément la sauvegarde chiffrée ; les profils et collections sont synchronisés par votre serveur Kovelyx, pas par ce formulaire.

    Guide : mettre en place un compte commun ↗

    Active l'enregistrement automatique dans ce navigateur. Après définition d'un mot de passe, vos clés API et vos sélections sont enregistrées localement. Fonction facultative.

    Vos clés restent sur votre appareil.

    Vos clés sont chiffrées sur cet appareil avec votre mot de passe de sauvegarde avant l'enregistrement. Ce mot de passe n'est envoyé à aucun serveur. Cette sauvegarde est indépendante du compte Kovelyx.

    L'enregistrement automatique est déjà configuré. Saisissez votre mot de passe pour restaurer vos clés et sélections.

    Enregistrez vos clés facultatives pour accélérer la configuration des services compatibles.

    Les jetons Trakt sont enregistrés via l'assistant sur l'instance AIO Metadata que vous avez autorisée. Ils ne se saisissent pas ici.

    Comment les clés sont protégées

    • Le mot de passe d'enregistrement ne quitte jamais cet appareil.
    • Les clés API sont chiffrées localement avec votre mot de passe de sauvegarde.
    • Sans votre mot de passe d'enregistrement, ces données ne peuvent pas être déchiffrées normalement.
    • L'enregistrement automatique est facultatif ; le site fonctionne également sans lui.
    • Cette sauvegarde locale est indépendante de toute connexion à un compte distant. Use “Lock on this computer” if someone else might use this browser.
